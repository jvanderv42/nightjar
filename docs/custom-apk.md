# Separately installable custom Nightjar APK

This is the production-style Android package for the Astra 2:

- **Package ID:** `com.butterpollo.client.custom`
- **Launcher name:** Nightjar (no Debug suffix)
- **Build:** non-debuggable, R8-minified, arm64-only, based on Nightjar 5.2.0
- **Installation:** alongside official `com.butterpollo.client`, without changing its settings

The build uses `assembleNonRootCustom`, which inherits the regular release configuration.
A dedicated persistent signing key is essential. The validation key generated by `android.yml` is
intentionally disposable and **must not** sign the APK a user installs: otherwise a later
GitHub Actions run will not be able to update it without losing settings.

## Create and safeguard a persistent key (once)

On Windows PowerShell, with JDK 21 installed:

```powershell
$signingFolder = Join-Path $env:USERPROFILE 'NightjarSigning'
New-Item -ItemType Directory -Path $signingFolder -Force | Out-Null
$keytoolPath = Join-Path $env:JAVA_HOME 'bin\keytool.exe'
$keystorePath = Join-Path $signingFolder 'nightjar-custom.p12'
& $keytoolPath -genkeypair -storetype PKCS12 -keystore $keystorePath `
  -alias nightjarCustom -keyalg RSA -keysize 3072 -validity 10000 `
  -dname 'CN=Nightjar Custom'
```

Choose a strong password, record it in a password manager, and back up the `.p12` file securely
outside GitHub. The password for the key is the same as the PKCS12 store password.

Set these four **GitHub repository Actions secrets** at
`Settings → Secrets and variables → Actions → New repository secret`:

| Secret | Value |
| --- | --- |
| `CUSTOM_NIGHTJAR_KEYSTORE_B64` | `[Convert]::ToBase64String([IO.File]::ReadAllBytes($keystorePath))` |
| `CUSTOM_NIGHTJAR_KEYSTORE_PASSWORD` | The PKCS12 keystore password |
| `CUSTOM_NIGHTJAR_KEY_ALIAS` | `nightjarCustom` |
| `CUSTOM_NIGHTJAR_KEY_PASSWORD` | The same PKCS12 password |

Do not paste passwords or keystore bytes into source files, issues, logs, chats or pull requests.
GitHub Actions secrets are injected into the signing job, not printed or uploaded as artifacts.

## Build and install

Run `Actions → Nightjar custom APK → Run workflow` on `main` after merging the
custom-build changes and configuring the secrets. Download the `nightjar-custom-arm64`
artifact and extract `nightjar-5.2.0-custom-arm64.apk`.

The first installation is a separate application. Later custom APKs must retain both
`com.butterpollo.client.custom` and this exact signing key, with a higher version code,
to update the custom app without clearing its settings. Keep official Nightjar installed until
the custom setup is verified.
